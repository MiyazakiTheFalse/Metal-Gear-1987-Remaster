# Original 1995 character dialogue production (no voice recordings bundled)

1. Cast or record distinct performances using `data/voice_performance_manifest.json`, which supplies the named speaker, exact remake-written subtitle, order and stable clip ID for all 39 current transceiver lines and one Gray Fox rescue cue. **These are not verified original 1987 dialogue lines or voice impressions of named franchise actors.**
2. Save each dry, authorised master to `assets/source/vo/raw/<speaker>/<clip>.wav`. Capture 48/96 kHz 24-bit where feasible, keep original takes unprocessed and free of clipping, hard noise gates, music and reverb. Record breaths and quiet phrases without boosting or over-articulating them.
3. Run `python tools/prepare_voice_assets.py --strict` with ffmpeg/ffprobe to measure and produce separate, consistently levelled 48 kHz mono PCM. Do not label this step finished while any master is missing. The filtering is deliberately restrained: radio voices retain articulatory clarity and personality, rather than sounding like thin synthetic beeps. Test dialogue against loud Shotmaker weapon cues, ambience and music; retain dry stems for mix work.
4. Open the Unreal Editor, enable Python Editor Script Plugin and run `Content/Python/import_character_vo.py`. It imports processed WAVs into `/Game/Audio/VO/<speaker>/<clip>`, never replaces existing assets automatically, and reports missing masters.
5. Listen to actual packaged playback with headphones and ordinary TV speakers. Verify voice clarity/subtitles without sound, scene/voice IDs, channel retune interrupt, skip/cancel, full transcript in mission log, music ducking, 720p text fit and retention of controls. VO must not complete or delay gameplay mission transactions.

Performance identities: young Snake analytical and restrained; Big Boss steady with protective authority; Schneider urgent but informed only by his own knowledge; human Fox fatigued yet precise; Shoot Gunner proud and physically intimidating; guards procedural and evidence-bound. **Actor timbre comes from casting/performance, not resampling, pitch-shifting or voice cloning another performer.** Never derive voiced samples from existing Metal Gear recordings without permission.

Current branch contains working SOURCE playback paths and this ingestion pipeline, but **zero finished or imported spoken performance assets**, no final spatial/ducking mix and no recorded lip-sync. Script authoring is not performance QA.
