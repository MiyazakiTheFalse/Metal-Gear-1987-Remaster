# Story / Continuity Reference — Later-series information that benefits the 1995 Metal Gear remake

**Status:** living research note, **NOT** permission to rewrite 1987 mission progression. Used together with [DOCTRINE_2D_TO_3D_MAPS.md](DOCTRINE_2D_TO_3D_MAPS.md).

## Canon priority and spoilers

1. **Original game facts (highest priority):** the 1995 Outer Heaven infiltration, Solid Snake as rookie FOXHOUND operative, Gray Fox's earlier mission, key prisoners and personnel, TX-55, and FOXHOUND commander Big Boss's betrayal. Reconstruct first.
2. **Subsequent canonical expansion/retcon:** *MG2: Solid Snake*, *MGS1–4*, *MGS3*, *Peace Walker*, *MGSV* add hindsight, character relationships and historical context. Use without creating impossible 1995 technology or erasing original encounters.
3. **Remake-only invention:** new documents, plausible architecture, minor side stories, optional conversations and extra stealth routes must be labelled proposals. Never present invention as already established canon.
4. **Player-facing spoiler discipline:** late-series revelations can be hinted at subtly in production design; preserve the original game's perspective for first-time players. A post-game contextual epilogue is preferable to front-loading the twist.

## Implementation filter (mandatory)

For every lore addition, enter it in a story change log with fields:
- Source game and exact on-screen scene, text or sourced guide citation.
- Claim classification: original / later-canon / proposed interpretation / remake-only.
- Date of in-world event and what the 1995 cast could reasonably know.
- Original scene/quest objective preserved? yes/no.
- Gameplay influence: cosmetic / optional discovery / mandatory mission. Mandatory changes require explicit review.
- Spoiler placement and user-facing disclosure.
- Verification against mission flags and map doctrine before implementation.

### First recommended batch

1. Build Outer Heaven as a credible, inhabited military-industrial base using warehouse, training, research and security logic—without touching source critical-path gates.
2. Add unobtrusive documents and environmental clues that enrich MSF → Diamond Dogs → Outer Heaven history.
3. Use Gray Fox and Dr. Madnar dialogue sparingly to add retrospective depth, not plot replacements.
4. Keep the Venom Snake contextual reveal under a late-game/postgame narrative gate.
5. Borrow MGSV controls and detection affordances, not its anachronistic gadgets or 1984 open-world structure.
