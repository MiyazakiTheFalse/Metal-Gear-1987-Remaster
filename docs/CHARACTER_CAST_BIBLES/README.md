The 1995 Snake protagonist has his own longer bible at ../SOLID_SNAKE_1995_PROTAGONIST_BIBLE.md. TX-55's encounter bible: ../TX55_METAL_GEAR_BOSS_BIBLE.md. Every significant cast member receives a separate file with **canon and knowledge horizon, motive, model and motion art direction, dialogue/performance, gameplay, spoiler vetoes, and actual tests**. C87 = original MSX2; CL = later canon; I = interpretation; U = unverified target J2ME. Two aliases never mean two separate characters (Shoot Gunner = Shotmaker; Arnold = Bloody Brad; Coward Duck = Dirty Duck; Grey = Gray Fox).

This catalogue covers all named 1987 mission-critical allies and human/robot bosses, plus narratively significant unnamed groups. The Hind D, tank, bulldozer and other machines are **encounter/vehicle asset dossiers**, not extra invented named humans. Additional distinct prisoner characters can be created when source extraction verifies identity.
