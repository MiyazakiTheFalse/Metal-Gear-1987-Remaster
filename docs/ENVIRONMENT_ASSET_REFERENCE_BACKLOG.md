# Environment Asset Reference Targets — status: research candidates

This file is a searchable production backlog rather than evidence that these exact objects exist in the J2ME game.

Each item names its source-game role, later-game *style or behavior* reference, and required original verification. Assets with an unverified original presence cannot be added as mandatory content.

All physical dimensions remain null until one of two events occurs: (a) exact native game geometry is decoded and converted with a documented scale decision, or (b) a provisional 3D blockout dimension is approved with camera/collision evidence. Never infer metres from pixel art alone.

Candidate asset classes include perimeter, door, corridor, industrial wall, elevator, stairwell, ventilation, consoles, machinery, crates, barracks, medical area, cameras, floodlights, guards, Snake and TX-55 endgame.

See data/environment_asset_targets.json and the six modelled starter modules in assets/greybox/. The latter are original provisional models that have passed static bounds checks, not final environment meshes.

Priority: exact original location and source map graph > modern third-person playability > lore-consistent industrial style > graphics polish.
